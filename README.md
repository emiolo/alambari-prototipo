# Protótipo React + TypeScript — Alambari

Protótipo frontend navegável recriado a partir do sistema legado PHP da Alambari. Utiliza dados simulados e não executa integrações, banco de dados, e-mail, boletos ou regras reais de backend.

## Executar localmente

1. Entre em frontend.
2. Execute npm install.
3. Execute npm run dev.

## Validar produção

Execute npm run build e npm run lint.

## Navegação demonstrada

- Painel com métricas, fluxo projetado, prioridades, atividade e ações rápidas.
- Menu administrativo para rebanho/plantel, imóveis/fazendas, estoque/frota, contas a pagar/receber, caixa, relatórios, tarefas, mensagens, portal/CMS e configurações.
- Busca local, filtros demonstrativos, detalhes laterais, formulários modais, confirmações e feedbacks.
- Portal público responsivo com Home, navegação institucional, páginas de pecuária/plantel, notícias e formulário de contato simulado.

Consulte ../ANALISE_LEGADO.md para o mapa consolidado das funcionalidades identificadas no PHP.
